## Expense Tracker App

A simple and responsive Expense Tracker Application built with HTML, CSS, and Vanilla JavaScript.

The application allows users to record income and expenses, view their total balance, and manage their transaction history. Transaction data is stored in the browser using localStorage, so it remains available after refreshing the page.

### Features

- Add income transactions
- Add expense transactions
- Enter transaction name
- Enter transaction amount
- Select transaction date
- Display total balance
- Display total income
- Display total expenses
- Display transaction history
- Delete transactions
- Automatically calculate balance
- Store transactions in localStorage
- Display newest transactions first
- Responsive design for desktop and mobile devices
