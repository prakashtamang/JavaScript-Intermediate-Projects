## OPT Input Field

A simple JavaScript project that demonstrates how to build an OTP (One-Time Password) input field using HTML, CSS, and JavaScript. It provides a smooth and user-friendly verification experience with automatic focus management and input validation.

### Features

- Automatically moves the cursor to the next input after entering a digit.
- Moves the cursor to the previous input when **Backspace** or **Delete** is pressed.
- Accepts only numeric input for OTP verification.
