## Product Search, Filter, Sort & Pagination

A responsive product listing application built with HTML, CSS, and JavaScript. The application fetches product data from the Fake Store API and provides search, category filtering, price sorting, and pagination functionality.

### Features

- Fetch products from Fake Store API
- Search products by name
- Filter products by category
- Sort products by price
  - Low to High
  - High to Low
- Number-based pagination
- Previous and Next pagination buttons
- Reset all filters
- Loading state
- Error handling
- Responsive product card layout
