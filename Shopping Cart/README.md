## JavaScript Shopping Cart

A simple and responsive Shopping Cart Application built using HTML, CSS, and Vanilla JavaScript.

This project demonstrates how to build shopping cart functionality using JavaScript DOM manipulation, event handling, template literals, and basic state management.

### Features

- Add products to the shopping cart
- Prevent duplicate products from being added
- Increase product quantity
- Decrease product quantity
- Remove products from the cart
- Display the number of items in the cart
- Automatically calculate the total price
- Open and close the shopping cart
- Buy Now functionality
- Display an alert when trying to purchase an empty cart
- Clear the cart after a successful purchase
- Save the cart to localStorage
- Responsive design
