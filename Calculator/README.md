## JavaScript Calculator

A simple and responsive calculator application built with HTML, CSS, and vanilla JavaScript. This project demonstrates fundamental JavaScript concepts such as DOM manipulation, event handling, functions, variables, conditional logic, and application state management.

### Features

- Perform basic arithmetic operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
- Enter numbers from 0 to 9
- Support decimal numbers such as 1.5, 10.25, etc.
- Delete the last entered digit using DEL
- Reset the calculator using RESET
- Calculate results using the = button
- Prevent multiple decimal points in a number
- Handle division by zero
- Display numbers with comma formatting
- Responsive and clean calculator interface
- Built with vanilla JavaScript without external libraries
