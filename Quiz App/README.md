## Quiz App

A simple JavaScript project that demonstrates how to build an interactive Quiz App using HTML, CSS, and JavaScript. Users can answer multiple-choice questions, navigate between questions, receive instant feedback on their answers, and view their final score and accuracy at the end of the quiz.

### Features

- Interactive quiz with 6 multiple-choice questions
- Four answer options for each question
- Highlights the correct answer in green
- Highlights the selected incorrect answer in red
- Prevents changing an answer after it has been selected
- Previous and Next navigation between questions
- Remembers selected answers while navigating
- Displays the current question number
- Calculates the final score automatically
- Shows the total number of correct and incorrect answers
- Displays the overall accuracy percentage
- Includes a Play Again button to restart the quiz
