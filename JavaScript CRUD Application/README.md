## JavaScript CRUD Application

A simple CRUD (Create, Read, Update, Delete) application built with HTML, CSS, and Vanilla JavaScript.

This project demonstrates how to create, display, edit, and delete data while using the browser's localStorage to persist data even after refreshing the page.

### Features

- Create new card records
- Read and display saved records in a table
- Edit/update existing records
- Delete records
- Store data using localStorage
- Retrieve saved data when the page loads
- Form validation
- Display validation error messages
- Confirmation before deleting a record
- Automatically update the table after Create, Update, or Delete
- Responsive and simple user interface
