## HTML Form Handling

A simple JavaScript project that demonstrates how to build and handle an HTML payment form using Vanilla JavaScript. The project covers form submission, input validation, DOM manipulation, displaying submitted data in a table, and storing data in the browser's `localStorage`.

### Features

- Create and handle an HTML form
- Validate required form fields
- Display validation error messages
- Collect form input values using JavaScript
- Create and manage JavaScript objects
- Display submitted data dynamically in a table
- Store form data in `localStorage`
- Retrieve saved data from `localStorage` when the page loads
- Delete individual records
- Confirm before deleting a record
- Automatically update the table after adding or deleting data
