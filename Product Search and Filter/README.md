## Product Search & Filter Application

A responsive Product Search & Filter Application built using HTML, CSS, and Vanilla JavaScript.

The application allows users to search products by name, filter products by category, price, and rating, and sort products using different sorting options.

### Features

- Search products by name
- Filter products by category
- Filter products by maximum price
- Filter products by minimum rating
- Sort products by:
  - Name: A-Z
  - Name: Z-A
  - Price: Low to High
  - Price: High to Low
  - Rating: High to Low
- Display the number of matching products
- Show a message when no products match the filters
- Clear all filters with one button
- Fully responsive design
- Dynamic product rendering using JavaScript
