## Number Pagination

A simple and responsive Number Pagination Application built using HTML, CSS, and Vanilla JavaScript.

This project demonstrates how to divide a list of items into multiple pages and navigate between them using numbered pagination buttons, Previous, and Next buttons.

### Features

- Display items with pagination
- Show a fixed number of items per page
- Numbered pagination buttons
- Previous and Next navigation
- Active page highlighting
- Disable Previous button on the first page
- Disable Next button on the last page
- Dynamic pagination generation using JavaScript
- Responsive and clean user interface
- Uses Vanilla JavaScript without external libraries
